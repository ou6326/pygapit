# Security policy

## Supported versions

Security fixes are provided for the latest stable pyGAPIT release. The latest
prerelease is also supported for issues relevant to the upcoming release.
Older releases may be asked to reproduce the issue on a supported version.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/ou6326/pygapit/security/advisories/new)
and include:

- the affected pyGAPIT version and installation features;
- the operating system, architecture, and Python version;
- a minimal reproduction or proof of concept;
- the expected impact and any known workaround.

Remove private, identifying, or unpublished research data before submitting a
report. You should receive an acknowledgement within seven days. We will
coordinate disclosure after the issue has been assessed and a fix is available.

Scientific correctness differences that do not create a security risk should
use the GAPIT 3.5 parity issue form instead.
